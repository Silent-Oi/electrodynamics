# ch0 起步

阶段目标
确认静电学所需的最低数学工具，并找出真正需要补强的部分。
最终目标是能够读懂并解释电动力学中场的积分形式与微分形式。

## 学习范围与深度

[] R/U：梯度、散度、旋度的几何和物理含义。
[] R：理解散度描述局域源汇、旋度描述局域环流。
[] U：线积分、面积分和体积分的对象与含义。
[] R/U：梯度基本定理、高斯散度定理、斯托克斯定理。
[] U：利用直角、柱和球坐标判断对称性；公式可查。
[] U：三维 Dirac δ 函数、点源表达和归一化性质。

### 暂不要求：

- 背诵冗长的矢量恒等式；
- 推导所有特殊坐标系公式；
- 完成第一章全部习题；
- 学习严格的分布理论；
- 进行大量复杂积分。

## 推荐学习方式

按需阅读 Griffiths 第一章中与以下内容有关的部分：
- 梯度、散度和旋度；
- 三个基本积分定理；
- 柱坐标、球坐标与对称性；
- Dirac δ 函数。
公式忘记可以查阅，但学习记录中应尽量写出你对物理结构的理解。

## 需要提交的学习记录

形式完全自由，不要求整理成正式笔记。请尽量覆盖：
- 梯度、散度和旋度分别描述什么，最好附一个直观例子；
- 高斯定理和斯托克斯定理分别连接哪些量；
- 面对球对称场，如何判断是否适合使用高斯面，以及高斯面如何选择；
- 如何用三维 δ 函数表示位于给定位置的点电荷密度；
- 尝试一次简单的积分形式与微分形式转换，并说明使用了哪个定理。
- 看书过程中不理解、只能照着推、对符号或方向不确定的地方，请如实保留，这些正是我后续审阅需要的信息。
