# 第二部分：静电学与边值问题

## 部分目标

这一部分覆盖 Griffiths 第二章、第三章以及项目 1“二维 Poisson/Laplace 求解器”。

核心目标不是积累静电学公式，而是建立完整的问题链：

\[
\text{电荷与边界条件}
\longrightarrow
\text{电场或电势的控制方程}
\longrightarrow
\text{方法选择}
\longrightarrow
\text{解析或数值求解}
\longrightarrow
\text{物理与数学验证}.
\]

完成后，应能把静电学同时看成：

- 电荷之间通过电场发生作用的问题；
- 由源和边界条件共同决定场的边值问题；
- Poisson/Laplace 方程可以解析求解或数值近似的问题。

这一结构是后续介质、导体边界条件、Maxwell 方程和二维 FDTD 的直接基础。

- [ ] **R/U**：解释电荷密度、边界条件和电势解之间的关系。
